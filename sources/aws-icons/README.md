確認日: 2026-11-12

- 出典: AWS Architecture Icons（公式） https://aws.amazon.com/architecture/icons/
- 取得したパッケージ: Icon-package_07312026（2026年7月31日版と思われる。ファイル名からの推定で、ページに明記はない）
  https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip
- 利用条件（公式ページの記述）: 「構成図の作成に、顧客とパートナーがこのツールキットとアセットを使うことを認めている」「ホワイトペーパー、プレゼンテーション、データシート、ポスターなどにもアイコンを置ける」。正式なライセンス条文は、このページには載っていない（サイト利用規約へのリンクのみ）。
- 使ったアイコン: Config / CloudTrail / EventBridge / SNS / SQS / Lambda / Cognito / API Gateway / DynamoDB / Bedrock AgentCore（5倍サイズのPNG）
- 使ったスライド: 用語解説①（10枚目）、用語解説②（12枚目）
- AgentCore Gateway と AgentCore Identity は、同じ AgentCore のアイコンを使った（個別のアイコンは、パッケージになかった）。
- MCP（Model Context Protocol）は AWS のサービスではないため、アイコンなし。
